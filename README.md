# TFM Project

This folder separates technical execution from thesis writing.

## Structure

- `planning/`: backlog, decisions, risks, and daily tracking.
- `development/`: source code, scripts, tests, and working data.
- `docs/`: technical and product documentation.
- `scripts/`: setup and automation utilities.

## Recommended Workflow

1. Plan and close tasks in `planning/` at the beginning and end of each day.
2. Implement features in `development/`.
3. Keep thesis drafts outside this project workspace.
